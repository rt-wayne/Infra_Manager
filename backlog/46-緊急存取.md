## 1. 目標與範圍

**含**
- SA v0.5 §5.11 緊急存取全部：送出即生效、24 小時補核准期限、申請人回報（僅本人、僅一次）、主管補核准／退回、異常結案（須填結案發現）、受影響帳號子表（D31）

### 3.5 synonym 與授權（待釐清，回填後才定 S1 腳本的 synonym 段）

第一階段的 public synonym 與 ap_user 授權怎麼建的，repo 沒有紀錄（只有 `im_acct_insp\src\main\resources\config\database.properties.example` 第 20 行一句「有 Public Synonym」；已登記第 48 項）。使用者以 RD_USER 執行下列三句**唯讀**查詢，結果回填到 3.6：

```sql
-- ① 有沒有 IM_EMG 開頭的表已存在（含其他 schema，避免與機房異動模組撞名）
SELECT OWNER, TABLE_NAME
  FROM ALL_TABLES
 WHERE TABLE_NAME LIKE 'IM\_EMG%' ESCAPE '\'
 ORDER BY OWNER, TABLE_NAME;

-- ② 第一階段的表與序列有哪些 synonym（public 或其他 schema 建的）
SELECT OWNER, SYNONYM_NAME, TABLE_OWNER, TABLE_NAME
  FROM ALL_SYNONYMS
 WHERE TABLE_NAME LIKE 'IM\_ACCT%' ESCAPE '\'
    OR TABLE_NAME LIKE 'SEQ\_IM\_ACCT%' ESCAPE '\'
    OR TABLE_NAME IN ('IM_DOC_SEQ', 'IM_EXEC_MAP', 'IM_ASSET_CLASS', 'IM_INSP', 'IM_INSP_ITEM', 'IM_INSP_RESULT')
 ORDER BY OWNER, SYNONYM_NAME;

-- ③ RD_USER 把第一階段的表與序列授權給誰、什麼權限
SELECT GRANTEE, TABLE_NAME, PRIVILEGE
  FROM USER_TAB_PRIVS
 WHERE TABLE_NAME LIKE 'IM\_ACCT%' ESCAPE '\'
    OR TABLE_NAME LIKE 'SEQ\_IM\_ACCT%' ESCAPE '\'
    OR TABLE_NAME IN ('IM_DOC_SEQ', 'IM_EXEC_MAP', 'IM_ASSET_CLASS', 'IM_INSP', 'IM_INSP_ITEM', 'IM_INSP_RESULT')
 ORDER BY GRANTEE, TABLE_NAME, PRIVILEGE;
```

②③ 除了 `IM_ACCT%` 另含序列與 6 張非 IM_ACCT_ 開頭的第一階段表：ap_user 取序列值、讀 IM_DOC_SEQ 等表同樣需要 synonym 與授權，只查 `IM_ACCT%` 會看不到。
